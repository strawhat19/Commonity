# Commonity app mockups — v1

Open [index.html](index.html) to review both concepts:

- **Neighborhood Feed:** a post-first home for anonymous local conversations.
- **Community Board:** a category-first Explore view for discovering nearby communities.

Each concept has mobile and desktop mockups in light and dark mode. The SVGs are editable; matching PNGs are included for quick sharing. `overview.png` compares all eight screens. The header uses the selected [Soft Point icon](../../logos/v4/03-soft-point.svg).

The fictional Brookside community keeps the examples location-neutral. The posting prompt and cards show anonymity without exposing a poster's exact location.

To regenerate the SVG and PNG files on macOS, run `python3 generate.py` from this folder.
