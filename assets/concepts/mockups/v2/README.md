# Commonity Home and Feed mockups — v2

Open [index.html](index.html) to compare two connected screens in mobile and desktop light/dark modes:

- **Home:** neighborhood activity, pastel category tiles, nearby community context, and a popular post preview.
- **Feed:** quick category filters, anonymous post composer, and local conversation cards.

The visuals follow the Community Board direction from `../v1/` and use the selected [Soft Point icon](../../logos/v4/03-soft-point.svg). All eight screens have editable SVGs and PNG exports; `overview.png` shows them together. The fictional Brookside location avoids implying a real user's precise location.

To regenerate the files on macOS, run `python3 generate.py` from this folder. The script uses the drawing helpers in `../v1/generate.py`.
