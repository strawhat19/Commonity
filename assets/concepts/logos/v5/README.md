# Commonity logo concepts — v5

Editable, standalone SVG app-mark directions. The square canvas matches the established icon format; none of these files replaces an earlier direction.

| File | Idea | Colors | Best use |
| --- | --- | --- | --- |
| `01-two-way-conversation.svg` | Two voices face a shared point. | Teal `#0DD5B2`, white, deep teal `#075D53` | Social and discussion surfaces |
| `02-local-network.svg` | The familiar pin contains connected neighbors. | Teal `#0DD5B2`, white, link teal `#0AAB92`, deep teal `#075D53` | Place and neighborhood surfaces |
| `03-people-form-c.svg` | Connected people trace an open C. | Teal `#0DD5B2`, white, deep teal `#075D53` | Small app icon and avatar |

Keep the rounded square when comparing these as app icons. For a stand-alone brand mark, remove `app-tile` and adapt the white shapes to the intended light or dark background. SVG element IDs identify parts for further editing.
