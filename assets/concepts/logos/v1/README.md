# Commonity logo concepts — v1

Open [index.html](index.html) to compare the three directions at logo and app icon sizes.

| Direction | Idea | Files |
| --- | --- | --- |
| Shared C | An open C faces one point: an individual voice joining the community. | `01-shared-c-*` |
| Conversation Pin | A C-shaped conversation inside a location pin. | `02-conversation-pin-*` |
| Common Ground | Four local groups frame one shared point. | `03-common-ground-*` |

All files are editable SVGs. The main green is `#0DD5B2`, taken from [Yik Yak's official site stylesheet](https://yikyak.com/style.css?version=3). The wordmarks use a system sans-serif font stack, so exact letter shapes may vary by device until a final typeface is chosen or text is converted to outlines.
