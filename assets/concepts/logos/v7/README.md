# Commonity logo concepts — v7

This round refines both [v6 concepts](../v6/README.md). The green `#0DD5B2`, white capital C, and navigation point remain. Square HUD corners and uneven dashed rings have been removed.

| Concept | Outline | Fill |
| --- | --- | --- |
| Capture Pin, with a small local point | [01-capture-pin-outline.svg](01-capture-pin-outline.svg) | [02-capture-pin-fill.svg](02-capture-pin-fill.svg) |
| Local Lock, with a short pinpoint stem | [03-local-lock-outline.svg](03-local-lock-outline.svg) | [04-local-lock-fill.svg](04-local-lock-fill.svg) |

Every circular bracket pair uses the same two radius-22 arcs centered at `(48, 43)`. Their endpoints mirror exactly across the vertical center line, and the top and bottom endpoints mirror across the horizontal center line. The filled pins have green circular windows so the white C and brackets stay visible. All four files are editable SVGs with descriptive element IDs.
