# Commonity logo concepts — v6

This round develops the established green `#0DD5B2` app icon into a local capture mark. Both editable SVGs put a white capital C on a white map navigation point and place HUD details around the C. Earlier versions remain available.

| File | Idea | Best use |
| --- | --- | --- |
| `01-capture-pin.svg` | White outline pin, segmented scan ring, capture brackets, and a small fixed location point. | App icon or place marker. |
| `02-local-lock.svg` | Solid white pin with a green window holding the white C and a compact locator HUD. | App icon or social avatar. |

Each shape has a named SVG ID for editing. The rounded green tile follows the existing Commonity icon format.
